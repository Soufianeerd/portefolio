# Portfolio — source canonique

## Décision

`Soufianeerd/portefolio` devient la base canonique du portfolio/agence.

`Soufianeerd/MonPortefolio` est une ancienne version orientée davantage profil MIAGE / carrière et sert uniquement de source de contenu avant suppression.

## Positionnement canonique

Le portfolio actuel doit présenter en priorité :
- activité de digitalisation ;
- création/refonte de sites ;
- outils métier et SaaS ;
- automatisation ;
- réalisations concrètes ;
- prise de contact / demande de rendez-vous.

Ce n'est pas principalement un CV ou une landing de recherche d'alternance.

## À récupérer de MonPortefolio

À conserver uniquement si encore exact :
- éléments crédibles de profil technique/fonctionnel ;
- compétences Business Analysis utiles au positionnement agence ;
- stack et compétences techniques ;
- projets supplémentaires réellement démontrables ;
- métadonnées SEO/OG utiles ;
- éléments de parcours qui renforcent la crédibilité commerciale.

## À ne pas reprendre automatiquement

- textes de recherche d'alternance devenus obsolètes ;
- compteurs non vérifiés ;
- slogans trop génériques ;
- projets non livrés présentés comme livrés ;
- informations contradictoires avec l'activité actuelle ;
- ancienne identité visuelle si elle affaiblit la landing agence.

## Règle IA

Toute modification future du portfolio doit partir de `portefolio`. L'ancien `MonPortefolio` ne sert que de référence jusqu'à fin de migration.
