- Le formulaire est branché à Netlify Forms.
- Les visiteurs peuvent indiquer un téléphone et un créneau souhaité.
- Après envoi : redirection vers `merci.html`.

Pour recevoir chaque demande par email dans `soufiane.erd@gmail.com` :
1. déployer ce dossier sur Netlify ;
2. ouvrir le projet Netlify ;
3. aller dans **Forms** ;
4. vérifier que le formulaire `contact` est détecté ;
5. dans les notifications de formulaires, ajouter une notification email vers `soufiane.erd@gmail.com`.

Important :
- ce formulaire permet une **demande de rendez-vous**, pas encore une réservation automatique dans un agenda ;
- pour une réservation instantanée sans double-booking, il faudra brancher une page de réservation Google Calendar / Cal.com / Calendly.
