# Assets vidéo — portfolio

Le bloc showreel de `index.html` attend ces deux fichiers **dans ce répertoire** :

- `showreel-soufiane.mp4` — vidéo optimisée H.264/AAC, environ 3,8 Mo (lecture seulement au clic).
- `showreel-poster.webp` — miniature statique, environ 33 Ko (chargement différé).

Les fichiers ont été préparés à partir de la vidéo fournie. Ils doivent être ajoutés à cette branche avant la fusion de la pull request. Ne pas renommer les fichiers.

Une fois les assets ajoutés, vérifier le chargement, le son, le bouton de fermeture (y compris Échap) et l'affichage sur mobile. Le lecteur crée l'élément `<video>` uniquement lorsqu'un visiteur demande à regarder.
